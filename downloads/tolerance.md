## 紅線檢查

- **壁厚 ≥1.2**：框壁 2.4、背板 5.5（通道上下 0.5 / 2.2）✔；0.5 的貼頸肉是唯一低於 1.2 的地方，只在通道底面，且是實心平面，FDM 100% 填充可接受
- **卡扣／配合餘隙 ≥0.2**：第 8 項 0.20 ✔；第 1 項 0.35 ✔
- **磁鐵不可外露**：第 6 項 0.8 前方肉 + 0.6 蓋片 ✔
- **不可有可拆小件**：蓋片與磁鐵都是永久固定 ✔

## 公差怎麼驗的（布林量體，不看圖）

`tmp/check_parts.py`，每一項都量體積：

- 模組 ∩ 框 = **0.000000 mm³**（放得進去）
- 兩個磁鐵窩淨空 = **0**；磁鐵前方肉厚 = **19.8 mm³**（期望 19.8，= π×2.8²×0.75）
- 底部托台存在 = **158 / 140 mm³**（一號／二號）
- 織帶通道貫通 = **0**；通道下方肉厚 **160 mm³**（期望 160 = 20×20×0.4）
- 公母片閉合 ∩ = **0**；母片凹槽淨空 = **0**
- **對照組**：框壁本體 30.8 mm³、母片本體 11.5 mm³ → 證明前面的「0」不是幾何壞掉造成的假通過

## 這一版修掉的三個錯（都是驗證抓出來的）

1. **框壁根本沒長出來**：只「減腔體」不會讓背板長高 → 要另外把外環柱減內腔柱「加」上去。第一版框壁高度只有 5.4（＝托台高度），量測時 `Z max = 5.40` 才發現。
2. **織帶孔只在頂上留一層皮**：孔切 3.7 但耳厚 4.2 → 剩 0.5 mm 蓋著，織帶穿不過去。改成貫穿整個耳厚。
3. **穿孔咬進框壁**：孔往內多切 1 mm，會在框壁上開一道通往模組腔的缺口（灰塵／水直通）。改成只從耳的外側往內切。

## 還沒量到的

- 磁鐵吸力、扣件插拔力、框耳抗拉 → 都要實體彈簧秤，目標：磁吸 8–15 N 脫開、模組 ≥4 N 不脫、扣件 ≥40 N 抗拉。
- 模組實際尺寸公差：目前用 3D 頁的標稱值，實機可能有 ±0.3。
